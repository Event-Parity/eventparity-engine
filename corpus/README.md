# Recorded corpus

Real testnet data, recorded 2026-10-07. Deterministic tests replay it offline.

| Directory | Range | Purpose |
|---|---|---|
| `testnet-2026-10-07` | ledgers 5071650-5071658 | Both adapters over real payments of every supported shape, plus unsupported and failed transactions |
| `retention-gap-2026-10-07` | ledgers 4950790-4950810 | A range straddling testnet RPC's retention boundary at recording time |
| `reports` | | Golden JSON reports generated by the engine (pinned by tests) |

## How it was made
1. `go run ./tools/mkcorpus corpus/testnet-2026-10-07/ground-truth.json` created three funded testnet accounts with friendbot (keys in memory only, never written) and submitted nine transactions. The ground truth lists what it built per transaction. The generator does not use any adapter or comparator.
2. `go run ./tools/record -from 5071650 -to 5071658 -out corpus/testnet-2026-10-07` fetched the range from the live endpoints through a recording HTTP transport, writing every raw response under `recorded/` and the two resulting streams. `retention-gap-2026-10-07` was recorded the same way for `-from 4950790 -to 4950810`.

## What was trimmed
To keep the repository small, fields no adapter reads were removed from recorded responses, and each file lists what was removed in its `trimmed` field:
- Horizon: `_links` inside each operation record (the page-level `_links.next` used for paging is kept).
- RPC: `resultMetaXdr`, `events`, `diagnosticEventsXdr` and the JSON-format twins of the XDR fields.

## What the two retention-gap RPC files show
Recording time 2026-10-07 UTC; RPC reported its oldest retained ledger as 4950802 at that moment, so ledgers 4950790-4950801 are a recorded gap. Re-recording later will give different bounds as RPC's window moves forward.

## Third-party payments
The same ledgers contain payments from other accounts (2 in the first corpus, plus those in the gap corpus). They have no independent ground truth; they are checked only by Horizon-versus-RPC agreement.
